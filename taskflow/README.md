# TaskFlow

TaskFlow is a minimalist task manager built to help you plan your day, stay focused, and never miss important reminders.

## Installation (Android)

1. Open this repository on GitHub.
2. Go to the Releases page.
3. Download the latest APK file.
4. Open the downloaded APK on your phone and install it.

If Android blocks installation:

1. Open Settings on your phone.
2. Allow installs from unknown apps for your browser or file manager.
3. Try the installation again.

Tip: Most modern phones should use the `arm64-v8a` APK.

## Quick Start

1. Open TaskFlow.
2. Tap Add Task.
3. Enter title, date, and reminder.
4. Save.
5. Mark tasks as complete as you finish them.

## User Manual

### Create a Task

1. Tap Add Task.
2. Enter a title and optional notes.
3. Set start time or due time.
4. Set reminders (for example 15 minutes before).
5. Save.

### Edit or Delete a Task

1. Open the task.
2. Change any fields you want.
3. Save updates, or choose Delete to remove it.

### Recurring Tasks (Weekly)

1. Enable recurrence while creating or editing a task.
2. Select one or more weekdays.
3. Save.

When a recurring task is completed, it automatically moves to the next valid day.

### Focus Mode

Use Focus Mode when you want to work in timed sessions.

1. Open Focus Mode.
2. Select a task (optional).
3. Start the timer.
4. Follow focus and break cycles.

### Reminders and Alarms

In Settings, you can:

- Enable or disable notifications
- Enable or disable alarm sounds
- Configure your morning prompt time
- Set default reminder behavior

### Share a Task

Open a task and use Share to send details through your preferred app.

### Completed Tasks

You can show or hide completed tasks from Settings depending on your preferred view.

## Troubleshooting

### Notifications are not showing

1. Make sure notifications are enabled in TaskFlow Settings.
2. Check Android system notification permission for TaskFlow.
3. Disable battery optimization for TaskFlow if reminders are delayed.

### Alarm has no sound

1. Enable Alarm Sounds in TaskFlow Settings.
2. Check phone volume and Do Not Disturb mode.

### App not installing

1. Confirm your Android version supports the app.
2. Try the `arm64-v8a` APK first.
3. Re-download the file and install again.

## Data and Privacy

TaskFlow stores your data locally on your device.
